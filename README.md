# hx-rules

코딩 에이전트(Codex 등)와 함께 **데이터를 받아 배정·최적화 도구와 로그인 웹을 만드는 업무 과제**를 할 때 쓰는 개인 작업 틀입니다. 특정 문제의 풀이나 코드는 들어 있지 않습니다.

| 파일 | 내용 |
|---|---|
| [CHECKLIST.md](CHECKLIST.md) | 한 장 요약: 180분 시간표, 단계마다 내가 할 일과 에이전트에 시킬 일, 지킬 것과 하지 말 것 |
| [AGENTS.md](AGENTS.md) | 에이전트 지침 틀. 대괄호를 과제에 맞게 채워 프로젝트 맨 위에 둡니다 |
| [PROMPTS.md](PROMPTS.md) | 단계별 프롬프트 틀 P1~P13, 확인 루틴, 화면 구성, 서술형 틀 |

## 쓰는 법
1. `CHECKLIST.md`를 먼저 읽고 시간표대로 움직입니다.
2. `AGENTS.md`는 그대로 쓰지 말고, 과제의 SPEC을 읽은 뒤 대괄호를 채워 작업 폴더에 새로 씁니다.
3. `PROMPTS.md`의 틀은 대괄호를 과제에 맞게 바꿔서 보냅니다. 틀을 그대로 붙여 넣지 않습니다.
